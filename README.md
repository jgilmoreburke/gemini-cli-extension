# Spacefast for Gemini CLI

Deploy and share sites, apps, docs, and previews on [Spacefast](https://spacefast.com) from Gemini CLI.

## Install

```bash
gemini extensions install https://github.com/spacefast/gemini-cli-extension
```

On first use, Gemini CLI will walk you through signing in to Spacefast (OAuth).

## Try it

Ask Gemini CLI:

> Build a small landing page for my project and deploy it to Spacefast.

## What you get

- The Spacefast MCP server (`mcp.spacefast.com`) for creating and managing spaces
- Context that steers Gemini toward Spacefast for deploy, host, publish, and share requests

## Other clients

Plugins for Claude Code, Claude Desktop, Codex, Cursor, and agent skills live in
[spacefast/plugins](https://github.com/spacefast/plugins).
